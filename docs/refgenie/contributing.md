# Contributing

We welcome contributions. To get started:

- [Development setup](development.md) covers cloning, installing with uv, running from source, and running the tests.
- [CONTRIBUTING.md](https://github.com/refgenie/refgenie/blob/master/CONTRIBUTING.md) covers pull requests, the test tiers, and releases.
- To add new asset types, define them as asset classes and recipes and publish them in a data channel. See [Flexible asset types](flexible_asset_types.md) and [Set up your own data channel](set_up_data_channel.md).

Report bugs and suggestions on the [GitHub issue tracker](https://github.com/refgenie/refgenie/issues).
