# Citing refgenie

If you use refgenie in your research, please cite:

- [Stolarczyk et al. (2020) *Refgenie: a reference genome resource manager*](https://doi.org/10.1093/gigascience/giz149). *GigaScience*. The introductory paper.
- [Stolarczyk et al. (2021) *Identity and compatibility of reference genome resources*](https://doi.org/10.1093/nargab/lqab036). *NAR Genomics and Bioinformatics*. Sequence-derived genome identifiers and provenance tracking.

For published work that uses refgenie, see [Studies using refgenie](uses_refgenie.md).
